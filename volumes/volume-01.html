# Atlas MCP companion

Pacote de skills e instalador mínimo para o servidor Atlas v1 (27 tools `atlas.*`).

Servidor canônico: [atlascommand.dev](https://atlascommand.dev) (`runtime/atlas_mcp_server.py`, 27 tools `atlas.*`).

O servidor Atlas governa missões, leases, artifacts, verificação Docker e evidência. A LLM executa o trabalho no próprio harness. Este pacote ensina o contrato MCP atual. Não há aliases para as 36 tools `megabrain.*` removidas.

## Contrato

| Onde | Valor |
| :--- | :--- |
| Superfície MCP | 27 tools `atlas.*`, schema fechado, sem alias |
| Identidade | conta `USER` (projetos) e conta `ADMIN` (keys). Atlas não tem roles técnicas |
| Endpoint | `https://mcp.atlascommand.dev/mcp` (prod) ou `http://127.0.0.1:<porta>/mcp` (efêmero) |
| Auth | `Authorization: Bearer <atlas_user_…\|atlas_admin_…>` |
| Hermes | servidor `atlas` → tools `mcp__atlas__atlas_<action>` |
| CLI | instalador + `call`; sem CLI de missão |

Handshake `POST /mcp` e keepalive não são uso. Uso é `tools/call` de `atlas.*`.

Publicação pública ainda não existe e não foi executada (requer Node >=18). Prepare o artefato beta verificável:

```bash
npm install -g ./dist/megabrain-cli-4.0.0.tgz
export MEGABRAIN_ENDPOINT=https://mcp.atlascommand.dev/mcp

# Rollback por reinstalar versão anterior
```


import { parseArgs } from 'node:util';
import { existsSync, readFileSync } from 'node:fs';
import process from 'node:process';

if (typeof process.loadEnvFile === 'function' && existsSync('.env')) {
  try { process.loadEnvFile(); } catch {}
}

const pkg = JSON.parse(readFileSync(new URL('../package.json', import.meta.url), 'utf8'));

const { values: flags, positionals } = parseArgs({
  args: process.argv.slice(2),
  options: {
    json: { type: 'boolean' },
    endpoint: { type: 'string' },
    dest: { type: 'string' },
    'write-mcp': { type: 'boolean' },
    help: { type: 'boolean', short: 'h' },
    version: { type: 'boolean', short: 'v' },
  },
  allowPositionals: true,
  strict: true,
});
if (flags.token !== undefined) { console.error('--token is not supported'); process.exit(1); }

const command = positionals[0];

if (flags.version || command === 'version') {
  console.log(pkg.version);
  process.exit(0);
}

if (flags.help || command === 'help' || !command) {
  console.log(`MegaBrain CLI v${pkg.version}

Usage:
  megabrain <command> [options]

Commands:
  login       Authenticate with Atlas MCP server
  status      Check connection and server status
  call        Execute an MCP tool or pipeline task
  setup       Configure environment and harness integrations
  version     Display CLI version
  help        Display help information

Options:
  -h, --help       Show help
  -v, --version    Show version
  --json           Output results in JSON format
  --dest <dir>     Destination directory for setup
  --write-mcp       Write MCP configuration during setup
  --endpoint <url> MCP server endpoint (default: $MEGABRAIN_ENDPOINT or https://mcp.atlascommand.dev/mcp)`);
  process.exit(0);
}

const SUBCOMMANDS = new Set(['login', 'status', 'call', 'setup']);
if (!SUBCOMMANDS.has(command)) {
  console.error(`Unknown command: '${command}'. Run 'megabrain --help' for available commands.`);
  process.exit(1);
}

// ponytail: direct file resolution for command modules; upgrade when complex routing needed.
const candidates = [
  new URL(`../src/commands/${command}.js`, import.meta.url),
  new URL(`../src/${command}.js`, import.meta.url),
];
const target = candidates.find((url) => existsSync(url));

if (!target) {
  console.error(`Command '${command}' is not yet implemented.`);
  process.exit(1);

try {
  const mod = await import(target.href);
  const handler = mod.run || mod.default || mod[command];
  if (typeof handler !== 'function') {
    throw new Error(`Command module '${command}' does not export a runnable function.`);
  }
  await handler({ positionals: positionals.slice(1), flags });
} catch (err) {
  console.error(`Error executing '${command}':`, err.message);
  process.exit(1);
}

```bash
# 1. Export soberano. Sem chave válida o kernel falha fechado.
megabrain call atlas.export_evidence '{"project_id":"proj_alpha","mission_id":"mis_hold"}'
```

## Cryptographic Invariants & Audit Guarantees

- **Hash Chain Continuity**: Each block enforces `hash == SHA-256(canonical_json(block - hash))` and links to `previous_hash`.
- **Non-Repudiation**: Verification receipts require valid Ed25519 signatures from trusted verifier keys.
- **Fail-Closed Verification**: Any hash divergence, malformed payload, or broken link halts downstream validation.

# Merkle Ledger & Evidence Pack Specification

Governs immutable cryptographic event recording via Atlas MCP (`https://mcp.atlascommand.dev/mcp`).

## Ledger Architecture (`atlas.export_evidence`)

Enforces append-only cryptographic provenance for mission lifecycles and DAG state transitions:
- **Audit Ledger**: Sequential SHA-256 hash chain verifying state sequence integrity.
- **Evidence Pack**: Self-contained bundle with ledger blocks, receipts, and execution artifacts.
- **Tamper Detection**: Any modification to historical block contents invalidates downstream hash links.

## SHA-256 Block Schema

Each ledger entry adheres to the canonical block structure:
- `index`: Monotonically increasing sequence integer (`uint64`).
- `previous_hash`: Hex-encoded SHA-256 digest of preceding block (`"0"` for genesis).
- `timestamp`: ISO-8601 UTC string recording exact transition time.
- `event_type`: Categorical identifier (`TASK_DISPATCHED`, `VERIFICATION_GATE`, etc.).
- `data`: Canonical serialized JSON object containing event context and assertions.
- `hash`: SHA-256 digest over `canonical_json({index, previous_hash, timestamp, event_type, data})`.

# Ed25519 Cryptographic Verification Receipts

Governs asymmetric attestation for Atlas receipts (`https://mcp.atlascommand.dev/mcp`).

## Asymmetric Attestation Protocol

Every verified task output is sealed with an asymmetric cryptographic signature:
- **Keypair Roles**: Atlas holds a private Ed25519 signing key; verifier instances register trusted public keys.
- **Receipt Attestation**: Verification receipts sign canonical summaries of task execution (`project_id`, `mission_id`, `task_id`).
- **Tamper Invariance**: Signatures provide non-repudiation and prevent forgery or retro-fitted test passes.

## Receipt Envelope & Verification Flow

Verification receipts encapsulate signature metadata within a canonical envelope:
- `signer_id`: Public identity of signing authority.
- `public_key`: Hex/Base64 Ed25519 public key corresponding to signing identity.
- `payload_hash`: SHA-256 digest of the canonical verification receipt body.
- `signature`: 64-byte Ed25519 signature generated over `payload_hash`.

Do not call `megabrain.verify_subtask`. Ask Atlas for `atlas.export_evidence` and `atlas.get_verification`.

Envelope/receipts seguem o schema real. Presença de referência ou campo `signature` não prova Ed25519. Root ou assinatura que não verifica não é aprovada. não prova Ed25519.

```bash
megabrain call atlas.health '{}'

megabrain call atlas.create_project '{"name":"Alpha"}'
```

# Mission Lifecycle Specification

Governs Atlas v1 mission state via MCP (`https://mcp.atlascommand.dev/mcp`). Companion CLI may call tools; it does not own mission logic.

## Lifecycle States

- **ACTIVE**: `atlas.create_mission` persisted an acyclic DAG. Tasks start `PENDING`.
- **RUNNING**: `atlas.claim_task` issued lease, fence, nonce; execution is `RUNNING`.
- **VERIFICATION**: `atlas.request_verification` created a `PENDING` run; worker records the signed result.
- **COMPLETED**: terminal DAG tasks submitted after `CHECK_EXECUTION_VERIFIED` when required.
- **ARCHIVED**: `atlas.archive_mission`. Stays archived.
- **FAILED**: unrecoverable check or exhausted lease; fail-closed.

```
ACTIVE ──> RUNNING ──┬──> VERIFICATION ──> RUNNING
                     ├──> COMPLETED
                     └──> ARCHIVED / FAILED
```

There is no CHECKPOINT state. Atlas v1 does not snapshot or roll back client files.

## Protocol

1. **Create** (`atlas.create_mission`): `project_id`, `mission_id`, `tasks`, optional `dependencies`.
2. **Claim** (`atlas.claim_task`): returns `execution_id`, `lease_id`, `fence_token`, `nonce`.
3. **Verify** (`atlas.request_verification` then `atlas.get_verification`).
4. **Submit** (`atlas.submit_task_result`) with the same lease/fence/nonce.
5. **Export** (`atlas.export_evidence`).

```bash
megabrain call atlas.create_mission '{"project_id":"proj_alpha","mission_id":"mis_hold","tasks":[{"task_id":"t_impl"}]}'
megabrain call atlas.claim_task '{"project_id":"proj_alpha","mission_id":"mis_hold"}'
```

`inspect` de missão inexistente devolve MISSION_NOT_FOUND. Mock/parser não é prova live.

# DAG Decomposition Rules

Governs task graphs persisted by `atlas.create_mission` (`https://mcp.atlascommand.dev/mcp`).

## Core Decomposition Principles

1. **Atomic Decomposition**:
   - Every complex mission decomposes into granular, non-overlapping subtasks (`PLANNING`, `IMPLEMENTATION`, `TESTING`, `INTEGRATION`).
   - Subtasks must produce discrete, testable deliverables with bounded file diffs.
2. **Single Responsibility Scope**:
   - Each subtask focuses strictly on one responsibility (e.g., single component, test suite, or schema).
   - Context is bounded to immediate dependencies to avoid token bloat and drift.
3. **Strict Explicit Dependencies**:
   - `depends_on_task_id` lists exact prerequisite task IDs; implicit ordering is forbidden.
   - Dependency graphs must be strictly acyclic; cycles trigger immediate validation failure.

# Topological Wave Partitioning

Waves are a local view of an Atlas DAG. Atlas does not expose `get_parallel_waves` or `execute_pipeline`.

## Partitioning Algorithm (Kahn's In-Degree)

1. **In-Degree Calculation**: Count unresolved incoming dependencies per task from `atlas.get_mission`.
2. **Wave Extraction**: Collect all tasks where `in_degree == 0` into the current wave.
3. **Graph Reduction**: Claim and finish the current wave; decrement dependents.
4. **Iterative Progression**: Repeat until all nodes are resolved or fail-closed if a cycle is detected.

## Parallel Execution and Path Isolation

- **Independent Concurrency**: Tasks in a wave may be claimed by separate harness sessions sharing the USER key.
- **Path Isolation**: Concurrent tasks must operate on mutually exclusive file paths.
- **Lock Enforcement**: Exclusive path locks live in the harness, not in Atlas. `arbitrate_concurrency` is not a server tool.

## Execution via CLI

```bash

node scripts/dag_validator.js tasks.json
```

Local tests use `test_commands` in the harness: execute the command and treat GREEN with exit_code: 0 only after real proof (não fabricar GREEN; negativos são NOT_EXECUTED ou MALFORMED_RESULT). Sem `wave_index`. Sem provider.

# WCAG Target Sizes & Accessibility Specification

Governs touch target sizing and color contrast verification for WCAG 2.1 AA/AAA compliance in the local harness via `@megabrain/cli`; the Atlas MCP server (`https://mcp.atlascommand.dev/mcp`) only stores the uploaded bytes or records the review via `atlas.*`.

## Target Size Compliance (WCAG 2.1 SC 2.5.5 & SC 2.5.8)

Ensures interactive elements are easily operable across touch and pointer devices:
- **Minimum Target Size**: All interactive elements (`<button>`, `<a>`, `<input>`, touch controls) require minimum $44 \times 44\text{px}$ footprint.
- **Padding Compensation**: Sub-44px elements must expand interactive hit-areas using transparent borders or tap padding.
- **Spacing Invariance**: Adjacent interactive targets must maintain at least $8\text{px}$ separation to eliminate accidental activation.

## Contrast & Focus Rings

- **Normal Text Contrast (SC 1.4.3)**: Relative luminance ratio $\ge 4.5:1$ against resolved background for text under 18pt (or 14pt bold).
- **Large Text Contrast**: Ratio $\ge 3.0:1$ for text $\ge 18\text{pt}$ (or $\ge 14\text{pt}$ bold) and graphical UI components.
- **Visible Focus Rings (SC 2.4.7)**: Unbroken focus indicators (`outline: 2px solid var(--focus-ring)`) with $\ge 3.0:1$ contrast against adjacent pixels.

#!/usr/bin/env node
import { readFileSync } from 'node:fs';
import { resolve } from 'node:path';
import { fileURLToPath } from 'node:url';
import process from 'node:process';

// ponytail: regex AST signature slicer; upgrade to tree-sitter for deep AST traversal
export function sliceAst(code = '', lang = 'auto') {
  if (typeof code !== 'string') return { lang, declarations: [], outline: '' };
  const detected = lang && lang !== 'auto'
    ? (lang.toLowerCase().includes('py') ? 'py' : lang.toLowerCase().includes('ts') ? 'ts' : 'js')
    : (/^[ \t]*(?:class\s+\w+|(?:async\s+)?def\s+\w+)/m.test(code) ? 'py' : (/\b(?:interface\s+\w+|type\s+\w+\s*=|:\s*(?:string|number|boolean|any|void|unknown|Promise)\b)/.test(code) ? 'ts' : 'js'));

  const decls = [];
  let curr = null;
  let ifaceDepth = 0;
  const isPy = detected === 'py';
  const startRe = isPy ? /^[ \t]*(?:class\s+\w+|(?:async\s+)?def\s+\w+)/ : /^[ \t]*(?:export\b|(?:async\s+)?function\*?\b|class\b|interface\b|type\b)/;
  const pyMatch = /^([ \t]*(?:class\s+\w+(?:\([^)]*\))?|(?:async\s+)?def\s+[\w$]+\s*\([^)]*\)\s*(?:->\s*[^:]+)?)\s*:)/;
  // ponytail: paren balance handles destructured params/types; upgrade to full tokenizer if quoted braces needed.
  const bodyIdx = (s) => {
    let p = 0;
    for (let i = 0; i < s.length; i++) {
      if (s[i] === '(') p++;
      else if (s[i] === ')') p = Math.max(0, p - 1);
      else if (s[i] === '{' && p <= 0) return i;
    }
    return -1;
  };
  const cleanJs = (s) => (/^[ \t]*(?:export\s+)?interface\b/.test(s) || /^[ \t]*export\s*\{/.test(s) ? s.trim() : (bodyIdx(s) >= 0 ? s.slice(0, bodyIdx(s)).trim() : s.replace(/\s*\{.*$/, '').trim()));
  const bDelta = (s) => (s.match(/\{/g) || []).length - (s.match(/\}/g) || []).length;

  for (const line of code.split('\n')) {
    const trimmed = line.trim();
    if (!trimmed || (!isPy && (trimmed.startsWith('//') || trimmed.startsWith('/*')))) continue;
    if (curr) {
      curr += ' ' + trimmed;
      if (ifaceDepth > 0) {
        ifaceDepth += bDelta(trimmed);
        if (ifaceDepth <= 0) {
          decls.push(cleanJs(curr));
          curr = null;
          ifaceDepth = 0;
        }
      } else if (isPy) {
        const m = curr.match(pyMatch);
        if (m) { decls.push(m[1]); curr = null; }
      } else if (bodyIdx(curr) >= 0 || curr.includes(';')) {
        decls.push(cleanJs(curr));
        curr = null;
      }
    } else if (startRe.test(line)) {
      if (isPy) {
        const m = line.match(pyMatch);
        if (m) decls.push(m[1]);
        else curr = line.trimEnd();
      } else if (/^[ \t]*export\s*\{/.test(line) || /^[ \t]*type\b/.test(line)) decls.push(trimmed);
      else if (/^[ \t]*(?:export\s+)?interface\b/.test(line) && trimmed.includes('{') && bDelta(trimmed) > 0) {
        curr = trimmed;
        ifaceDepth = bDelta(trimmed);
      } else if (bodyIdx(trimmed) >= 0) decls.push(cleanJs(trimmed));
      else if (line.includes(';') || (!line.includes('(') && !line.includes('function') && !line.includes('class'))) decls.push(trimmed);
      else curr = trimmed;
    }
  }
  if (curr && ifaceDepth > 0) decls.push(`${cleanJs(curr)} [unterminated interface: syntax outside slicer capability]`);
  return { lang: detected, declarations: decls, outline: decls.join('\n') };
}

export default sliceAst;

const isMain = process.argv[1] && resolve(process.argv[1]) === fileURLToPath(import.meta.url);
if (isMain) {
  const args = process.argv.slice(2);
  if (args.includes('--help') || args.includes('-h')) {
    console.log(`MegaBrain AST Context Slicer\n\nUsage:\n  node scripts/ast_slice.js [file] [flags]\n  cat file | node scripts/ast_slice.js [flags]\n\nFlags:\n  --json           Output JSON object instead of raw outline\n  --lang=js|ts|py  Force language parser\n  --help, -h       Show help`);
    process.exit(0);
  }
  try {
    const isJson = args.includes('--json');
    const langFlag = args.find((a) => a.startsWith('--lang='));
    let lang = langFlag ? langFlag.split('=')[1] : 'auto';
    const file = args.find((a) => !a.startsWith('-'));
    if (lang === 'auto' && file) {

export function validateDAG(tasks = []) {
  if (!Array.isArray(tasks)) return { valid: false, cycles: [], missing_dependencies: [], waves: [] };

  const seenIds = new Set();
  for (const t of tasks) {
    const id = t ? t.id : undefined;
    const idOk = (typeof id === 'string' && id.length > 0) || (typeof id === 'number' && Number.isFinite(id));
    if (!idOk) return { valid: false, cycles: [], missing_dependencies: [], waves: [], error: 'INVALID_ID' };
    if (seenIds.has(id)) return { valid: false, cycles: [], missing_dependencies: [], waves: [], error: 'DUPLICATE_ID' };
    seenIds.add(id);
  }

  const inDegree = new Map();
  const dependents = new Map();
  const knownIds = new Set(tasks.map((t) => t.id)), missing_dependencies = [];

  for (const t of tasks) {
    inDegree.set(t.id, 0);
    dependents.set(t.id, []);
  }

  for (const t of tasks) {
    // Canonical dependencies has documented precedence over legacy depends_on
    const raw = t.dependencies ?? t.depends_on;
    const deps = Array.isArray(raw) ? raw : [];
    for (const dep of new Set(deps)) {
      if (!knownIds.has(dep)) { if (!missing_dependencies.includes(dep)) missing_dependencies.push(dep); }
      else { inDegree.set(t.id, inDegree.get(t.id) + 1); dependents.get(dep).push(t.id); }
    }
  }

  const waves = [];
  let currentWave = [];
  for (const t of tasks) {
    if (inDegree.get(t.id) === 0) currentWave.push(t.id);
  }

  let processed = 0;
  while (currentWave.length > 0) {
    waves.push(currentWave);
    processed += currentWave.length;
    const nextWave = [];
    for (const id of currentWave) {
      for (const nextId of dependents.get(id) || []) {
        const deg = inDegree.get(nextId) - 1;
        inDegree.set(nextId, deg);
        if (deg === 0) nextWave.push(nextId);
      }
    }
    currentWave = nextWave;
  }

  const valid = processed === tasks.length && missing_dependencies.length === 0;
  const cycles = valid ? [] : tasks.filter((t) => (inDegree.get(t.id) || 0) > 0).map((t) => t.id);

  return { valid, cycles, missing_dependencies, waves };
}

export function canonicalStringify(val) {
  if (val === null || typeof val !== 'object') return JSON.stringify(val);
  if (Array.isArray(val)) return `[${val.map((v) => (v === undefined ? 'null' : canonicalStringify(v))).join(',')}]`;
  const keys = Object.keys(val).filter((k) => val[k] !== undefined).sort();
  return `{${keys.map((k) => `${JSON.stringify(k)}:${canonicalStringify(val[k])}`).join(',')}}`;
}

export function computeBlockHash(block) {
  if (!block || typeof block !== 'object') return '';
  const { hash: _, ...payload } = block;
  return createHash('sha256').update(canonicalStringify(payload)).digest('hex');
}

export function verifyLedger(blocks) {
  if (blocks && typeof blocks === 'object' && !Array.isArray(blocks)) {
    const extra = Object.keys(blocks).filter((k) => k !== 'blocks');
    if (extra.length > 0) {
      return { valid: false, blocks_verified: 0, errors: [`Unsupported envelope keys: ${extra.join(', ')}`] };
    }
  }
  const list = Array.isArray(blocks) ? blocks : (Array.isArray(blocks?.blocks) ? blocks.blocks : null);
  if (!list) return { valid: false, blocks_verified: 0, errors: ['Ledger must be an array of blocks'] };
  if (list.length === 0) return { valid: true, blocks_verified: 0, errors: [] };

  const errors = [];
  const isGenesisPrevValid = (prev) =>
    prev === null || prev === undefined || prev === 0 || prev === '0' || prev === '' ||
    (typeof prev === 'string' && /^0{64}$/.test(prev));

  for (let i = 0; i < list.length; i++) {
    const block = list[i];
    if (!block || typeof block !== 'object') {
      errors.push(`Block ${i}: block must be an object`);
      continue;
    }

    const isSafeIndex = typeof block.index === 'number' && Number.isSafeInteger(block.index);
    if (i === 0) {
      if (!isSafeIndex || block.index !== 0) {
        errors.push(!isSafeIndex ? 'Block 0: index must be a safe integer' : 'Block 0: genesis index must be 0');
      }
      if (!isGenesisPrevValid(block.previous_hash)) {
        errors.push(`Block 0: invalid previous_hash (${block.previous_hash})`);
      }
    } else {
      if (!isSafeIndex || block.index !== i) {
        errors.push(!isSafeIndex ? `Block ${i}: index must be a safe integer` : `Block ${i}: index sequence mismatch`);
      }
      const prevHash = list[i - 1]?.hash;
      if (block.previous_hash !== prevHash) {
        errors.push(`Block ${i}: previous_hash mismatch (expected ${prevHash}, got ${block.previous_hash})`);
      }
    }

    const computed = computeBlockHash(block);
    if (!block.hash || block.hash !== computed) {
      errors.push(`Block ${i}: hash mismatch (declared ${block.hash}, computed ${computed})`);
    }
  }

  return { valid: errors.length === 0, blocks_verified: list.length, errors };
}

export default verifyLedger;

  }

export function parseColor(str) {
  // ponytail: validates RGB [0..255]; upgrade if color spaces beyond RGB are supported
  if (str && typeof str === 'object') {
    return [str.r, str.g, str.b].every((v) => Number.isInteger(v) && v >= 0 && v <= 255)
      ? { r: str.r, g: str.g, b: str.b }
      : null;
  }
  if (typeof str !== 'string') return null;
  let h = str.trim().replace(/^#/, '');
  if (h.length === 3) h = h.split('').map((c) => c + c).join('');
  if (h.length !== 6 || !/^[0-9a-fA-F]{6}$/.test(h)) return null;
  const n = parseInt(h, 16);
  return { r: (n >> 16) & 255, g: (n >> 8) & 255, b: n & 255 };
}

export function getLuminance(color) {
  const rgb = parseColor(color);
  if (!rgb) return 0;
  const srgb = [rgb.r, rgb.g, rgb.b].map((v) => {
    const c = v / 255;
    return c <= 0.04045 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4;
  });
  return 0.2126 * srgb[0] + 0.7152 * srgb[1] + 0.0722 * srgb[2];
}

export function getContrastRatio(fg, bg) {
  const l1 = getLuminance(fg), l2 = getLuminance(bg);
  return (Math.max(l1, l2) + 0.05) / (Math.min(l1, l2) + 0.05);
}

export function checkWcag(params = {}) {
  const fg = params.fg ?? params.foreground, bg = params.bg ?? params.background;
  const validColors = Boolean(parseColor(fg) && parseColor(bg));

  const passAA = validColors && ratio >= 4.5, passLarge = validColors && ratio >= 3.0;

    if (v === undefined) return 44;

    if (typeof v === 'string' && /^\d+(\.\d+)?$/.test(v.trim())) return Number(v);
    return 0;
  };
  const width = parseDim(params.width), height = parseDim(params.height);
  const targetPass = width >= 44 && height >= 44;
  return {
    contrast: { ratio, passAA, passLarge },
    targetSize: { pass: targetPass, width, height },
    valid: Boolean(passAA && targetPass),
  };
}

async function sendRpc(method, params = {}, options = {}) {
  const endpoint = validateEndpoint(options.endpoint || getEndpoint());
  const token = options.token !== undefined ? options.token : getToken();
  const origin = new URL(endpoint).origin;

  const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json, text/event-stream",
    "Authorization": token ? `Bearer ${token}` : undefined,
    "Origin": origin,
    ...options.headers
  };
  if (!headers["Authorization"]) delete headers["Authorization"];
  headers["MCP-Protocol-Version"] = "2026-07-28";
  headers["Mcp-Method"] = method;
  if (method === "tools/call" && params.name) headers["Mcp-Name"] = params.name;
  params._meta = { ...(params._meta || {}), "io.modelcontextprotocol/protocolVersion": "2026-07-28" };
  params._meta["io.modelcontextprotocol/clientCapabilities"] = params._meta["io.modelcontextprotocol/clientCapabilities"] || { tools: {} };
  params._meta["io.modelcontextprotocol/clientInfo"] = params._meta["io.modelcontextprotocol/clientInfo"] || { name: "atlas-cli", version: "4.0.0" };

  const id = Date.now();
  const res = await fetch(endpoint, {
    method: "POST",
    headers,
    body: JSON.stringify({
      jsonrpc: "2.0",
      id,
      method,
      params
    }),
    signal: options.signal
  });

  if (!res.ok) {
    let msg = `HTTP ${res.status}: ${res.statusText}`;
    try {
      const errData = await res.json();
      if (errData?.error?.message) msg = `${msg} - ${errData.error.message}`;
    } catch {}
    throw new Error(msg);
  }

  const contentType = res.headers.get("content-type") || "";
  const match = (m) => Boolean(m && typeof m === "object" && m.jsonrpc === "2.0" && m.id === id && ("result" in m || "error" in m));
  let data;
  if (contentType.includes("text/event-stream")) {
    const text = (await res.text()).replace(/\r\n/g, "\n").replace(/\r/g, "\n");
    for (const frame of text.split(/\n{2,}/)) {
      const lines = frame.split("\n").filter((l) => l.startsWith("data:")).map((l) => l.slice(5).replace(/^ /, ""));
      if (!lines.length) continue;
      try {
        const m = JSON.parse(lines.join("\n"));
        if (match(m)) {
          data = m;
          break;
        }
      } catch {}
    }
  } else {
    try {
      const m = await res.json();
      if (match(m)) data = m;
    } catch {}
  }

  if (!data) throw new Error("Empty or invalid response from server");
  if (data.error) {
    throw new Error(data.error.message || `RPC Error ${data.error.code}`);
  }
  return data.result;
}
